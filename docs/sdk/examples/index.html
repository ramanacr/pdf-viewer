PDF Viewer embed SDK: examples

SDK documentation

Each page embeds the viewer with pdfviewer-embed.js. The PDF is written by the page itself (sample-pdf.js), so nothing is downloaded but the viewer, and nothing is uploaded. View the source of a page to copy its code.

  • Full window: the viewer fills the page, with the side panel. Add ?url=… to open another PDF (its server must allow CORS).
  • Sized container: a fixed box in an article, with a full-screen button.
  • In line: every page in the flow of the article; the article scrolls.
  • Light box: the viewer opens over the page and closes back to it.
  • Events and APIs: every event in a log, and buttons for each API.
  • File picker: open a PDF from your device with content.promise.

Frameworks (copy into your app)

These files are not run here. Copy one into your app and change the script URL to where you serve the viewer.
