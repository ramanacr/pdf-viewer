The installer (PdfViewerSetup.exe) and the portable PdfViewer.exe are on GitHub releases: Windows 10 version 2004 or later, or Windows 11, x64, with the .NET 9 Desktop Runtime. They are signed with the project's own self-signed certificate.

One engine

On Windows, in the browser and on Android

The engine, PdfEngine.Vector, is pure C# (.NET 9). The published app contains no PDFium.

Features

Everything you do with a PDF

It views, searches, annotates, measures, stamps, fills forms, signs, redacts, edits text and images, tags for accessibility, converts to PDF/A, checks print output, and exports to Word, Excel and PowerPoint.

{% include icon.html name="view" %} View

Continuous, single-page and facing views; zoom from 25 % to 1600 %, sharp at every zoom; tabs, bookmarks, thumbnails, night mode, full screen and navigation history.

{% include icon.html name="read" %} Read

Read mode that screen readers can navigate, tagged-PDF reading order, Read Aloud, PDF/UA-1 accessibility check, and Make Accessible (auto-tagging).

{% include icon.html name="search" %} Select and search

Word-processor text selection, search with a results list, and OCR for scanned pages (Windows OCR, on this computer).

{% include icon.html name="comment" %} Comment and measure

Highlights, notes, shapes and ink; distance, perimeter and area measuring with snapping; standard, dynamic and custom stamps; annotation edit handles.

{% include icon.html name="edit" %} Edit

Text and images in place, page organisation, merge and split, headers, footers, watermarks and Bates numbers, reduce file size, compare documents.

{% include icon.html name="sign" %} Forms, signatures and security

Fill and flatten forms, sign (PAdES-B-LT and B-LTA) and verify signatures, password protection (AES-256), true redaction.

{% include icon.html name="convert" %} Create and convert

PDF from images, a scanner or Office files; PDF/A; export to Word, Excel, PowerPoint, text and images.

{% include icon.html name="print" %} Print production

Print with live preview, Output Preview (separations, overprint, total ink) and Preflight.

{% include icon.html name="type" %} Fonts a PDF does not embed

Arabic and Indic shaping, a fallback font for each missing character, and the right Chinese, Japanese or Korean font for the language.

Privacy and safety

A document is data. It never acts.

A PDF can carry JavaScript, launch actions, embedded files and remote references. Many viewer vulnerabilities come from these features.

  • {% include icon.html name="noscript" %}No script engineThe engine has no JavaScript interpreter. A test checks that no JavaScript runtime ships with the app.
  • {% include icon.html name="shield" %}Active content is never runJavaScript, /Launch actions and embedded files are parsed, reported and left inert.
  • {% include icon.html name="eye-off" %}No telemetry, no accountNothing about you or your documents is recorded or sent. There is no sign-in and no cloud storage.
  • {% include icon.html name="wifi-off" %}Network only when you askThe update check is off until you allow it. Optional components download only when you ask.
  • {% include icon.html name="engine" %}Its own enginePure C# on .NET 9. The published app contains no PDFium.
  • {% include icon.html name="list" %}Published bill of materialsEvery release ships CycloneDX and SPDX SBOMs.
  • {% include icon.html name="license" %}Open sourceMIT licence. Read the code, build it, and take part.
  • {% include icon.html name="check" %}Signed releasesBuilt only by this repository's release workflow from tagged source. Code signing policy.

For developers

Put the engine in your web page or your .NET app

The same engine is a script for web pages and a set of NuGet packages. Both are previews: the API can change before version 1.0.

Show PDF files in your web page. The API follows the Adobe PDF Embed API, with no client ID, no server and no telemetry.
